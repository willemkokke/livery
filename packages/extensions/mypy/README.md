# livery-extensions-mypy

mypy as a check of the livery workshop. Listed as `mypy` in a workspace's
`[workspace] extensions`, it registers `typecheck.mypy`, which checks linux,
darwin and win32, and writes the root `mypy.ini` the check and a bare `mypy`
read.
