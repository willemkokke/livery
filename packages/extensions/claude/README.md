# livery-extensions-claude

Claude Code for the livery workshop. Listed as `claude` in a workspace's
`[workspace] extensions`, it writes the `CLAUDE.md` Claude Code reads,
the guidance it imports under `.workshop/fragments/`, and `.claude/`:
every listed extension's skills and hooks, and the settings that wire
the hooks to its `fm hooks.*` verbs.
