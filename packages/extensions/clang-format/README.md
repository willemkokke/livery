# livery-extensions-clang-format

clang-format as a check of the livery workshop. Listed as `clang-format` in a
workspace's `[workspace] extensions`, it registers `format.clang-format`, which
formats each native package's C and C++ files, and writes the `.clang-format`
each native package carries.
