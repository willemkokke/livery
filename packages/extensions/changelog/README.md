# livery-extensions-changelog

Changelogs for the livery workshop. Listed as `changelog` in a
workspace's `[workspace] extensions`, it writes each package's
`CHANGELOG.md` entry through git-cliff as the release train releases
the package, and gives every package the `cliff.toml` the entry is
written from.
