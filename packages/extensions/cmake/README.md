# livery-extensions-cmake

CMake as an extension of the livery workshop. Listed as `cmake` in a
package's `extensions`, it configures and compiles the package's gate
build with Ninja, runs its tests through ctest, and measures its native
suites for coverage while the workspace lists coverage.
