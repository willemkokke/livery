# livery-extensions-pyrefly

pyrefly as a check of the livery workshop. Listed as `pyrefly` in a
workspace's `[workspace] extensions`, it registers `typecheck.pyrefly`, which
checks every platform at once, and writes the root `pyrefly.toml` the check
and a bare `pyrefly` read.
