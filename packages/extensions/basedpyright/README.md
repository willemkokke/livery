# livery-extensions-basedpyright

basedpyright as a check of the livery workshop. Listed as `basedpyright` in
a workspace's `[workspace] extensions`, it registers `typecheck.basedpyright`
and writes the root `pyrightconfig.json` the check and the editor read;
listed as `basedpyright[typecomplete]`, it also registers
`typecomplete.basedpyright`.
